# Project-ML-Healt-Track
This is a Machine learning project, to predict and predict cardiovascular pathologies, using data set with basic vital signatures

This project compare 3 main algorithms:
 - Random Forest
 - Xgboost
 - KNN

And deliver the most important and popular indicators on landscape Data science

- AUC - ROC
- Accuracy
- F1 - Score
- Recall over to 90%
